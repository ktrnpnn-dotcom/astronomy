# Небо сейчас

Мобильный веб-прототип для людей, которые не следят за небом постоянно, но иногда хотят понять: что реально можно увидеть сейчас, когда и куда смотреть.

Приложение не заменяет планетарий. На первом экране — короткий повод выйти. На карте — камера телефона и положение Луны, Солнца, Венеры, Юпитера и Сатурна.

## Основной сценарий

1. На экране «Сегодня» видно одно главное событие.
2. Кнопка «Показать, куда смотреть» открывает карту.
3. После доступа к камере и геолокации приложение считает, что сейчас над горизонтом.
4. Кнопка «Калибровать» запрашивает ориентацию телефона. На iPhone это отдельное разрешение.
5. Если компас есть, подписи ложатся на изображение камеры. Если нет — остаётся схема горизонта и ползунок направления.
6. «Вижу» записывает объект в альбом на этом телефоне. «Не вижу» объясняет, почему так бывает, и предлагает ближайшую альтернативу.

## Технологии

- Next.js (App Router) и TypeScript
- Tailwind CSS
- lucide-react
- astronomy-engine — локальный расчёт, без сетевого API положений планет
- GitHub Pages — HTTPS-публикация статической сборки

Данные альбома, города и настроек лежат в `localStorage`. Базы, входа и аналитики нет.

## Как запустить локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 на компьютере. Демо-режим работает сразу. Камера, геолокация и компас на телефоне с локального адреса компьютера не заработают: Safari отдаёт их только в защищённом контексте.

Проверка сборки:

```bash
npm run lint
npm run build
```

## Как опубликовать: GitHub → GitHub Pages

Раньше для публикации использовался GitHub Pages. Этот проект собирается в статическую папку `out` и выкладывается тем же способом. Отдельный хостинг не нужен.

1. Создайте пустой репозиторий на GitHub.
2. В папке проекта:

```bash
git init
git add .
git commit -m "Add the sky-now mobile prototype"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

3. На GitHub откройте репозиторий → Settings → Pages.
4. В разделе Build and deployment выберите Source: GitHub Actions.
5. Дождитесь зелёного запуска workflow `Deploy GitHub Pages`.
6. Адрес появится в Settings → Pages и в логе деплоя. Для обычного репозитория это:

```text
https://ВАШ_АККАУНТ.github.io/ВАШ_РЕПОЗИТОРИЙ/
```

Если репозиторий называется `ВАШ_АККАУНТ.github.io`, сайт откроется в корне домена. Сборка сама подставляет префикс `/имя-репозитория` для проектных сайтов GitHub Pages.

## Почему для камеры и геолокации нужен HTTPS

iPhone отдаёт камеру, геолокацию и датчик ориентации только со страницы в защищённом контексте. Таким контекстом считается `https://` и `localhost` на самом телефоне. Сайт, открытый по `http://` с компьютера в той же сети, разрешения не получит. GitHub Pages как раз отдаёт HTTPS.

Разрешения запрашиваются только после нажатия кнопки, не при загрузке страницы.

## Как проверить на iPhone 16 Pro Max

1. Откройте HTTPS-адрес в Safari, не во встроенном браузере другого приложения.
2. Для домашнего экрана: Поделиться → На экран «Домой». Это ярлык PWA, не системный виджет.
3. Пройдите сценарий «Показать, куда смотреть» или на вкладке «Карта» нажмите «Открыть карту неба».
4. Разрешите камеру. Нужна задняя камера.
5. Разрешите геолокацию. Если откажете, выберите город вручную.
6. Нажмите «Калибровать» и разрешите доступ к движению и ориентации. Затем поверните телефон восьмёркой.
7. Держите телефон вертикально. Статус «Компас откалиброван» значит, что датчик подключён и показания стабильны. Это не обещание абсолютной точности.
8. Если компас недоступен, смотрите схему и двигайте ползунок «Направление».
9. Кнопка «Посмотреть демо» открывает сцену «Москва, 21:20» без разрешений.

Если Safari уже запомнил отказ: Настройки → Safari → Камера / Геолокация, либо значок «аа» в адресной строке → Настройки веб-сайта.

## Что считается по-настоящему

- Азимут и высота Солнца, Луны, Венеры, Юпитера и Сатурна для текущего времени, широты и долготы. Высота наблюдателя в расчёте равна 0.
- Азимут: 0° север, 90° восток, 180° юг, 270° запад.
- На карте остаются объекты выше горизонта. Солнце не предлагается «найти»: есть только предупреждение не смотреть на него в камеру.
- Закат и конец гражданских сумерек на ленте «Окна неба» для выбранного города.
- Запись «Вижу» в альбом через `localStorage`.

Поле зрения камеры для наложения подписей задано приблизительно: 60° по горизонтали и 45° по вертикали. В коде это помечено как TODO на калибровку конкретного телефона.

## Что является демо или макетом

- МКС и её траектория. Реального расчёта по TLE нет, в интерфейсе стоит пометка «демо».
- Погода, облачность и городская засветка.
- Линии «слоя созвездий»: это рисунок, не распознавание звёзд.
- Карточки ленты «Сегодня»: учебные примеры. Часы на карточке могут не совпасть с живой картой.
- Макеты виджетов в профиле. Это картинки, не виджеты домашнего экрана.
- Ночное зрение: красная палитра для просмотра, не полевое испытание.
- Service worker и полный офлайн: TODO.

PWA не умеет ставить системные виджеты на домашний экран iOS. Для WidgetKit нужно отдельное нативное приложение на Swift.

## Ограничения карты

Совпадение подписи с небом зависит от компаса, гироскопа, геолокации, чехла, металла рядом и того, как телефон держит человек. Пока ориентация не разрешена или показания дрожат, приложение не рисует «точный» слой поверх камеры и пишет «Ручной», «Уточняем направление» или «Поверните телефон восьмёркой».

## Следующие шаги
